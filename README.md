# polln

**Visualized spreadsheets for tile intelligence** — PLATO tiles rendered as interactive, explorable spreadsheet views with real-time updates.

## What This Gives You

- **Tile-to-spreadsheet** — PLATO tiles rendered as rows/columns
- **Real-time updates** — live tile changes reflected in the spreadsheet view
- **Interactive exploration** — sort, filter, and drill into tile data
- **Multi-room views** — combine tiles from multiple PLATO rooms in one view

## How It Fits

Visualization layer for PLATO. Complements `plato-room` (storage) and `plato-observe` (monitoring) with a spreadsheet-style interface for tile data.
